# 快手作品数据分析

只通过 Agent 已提供的白名单业务工具工作。不要请求、读取或输出 Cookie、Token、环境变量、文件路径，也不要执行命令、登录或发布操作。

## 选择查询模式

1. 用户从发布中心点击“分析数据”或给出唯一 `publishRecordId` 时，默认调用 `get_published_video_metrics`。
2. 用户明确要求比较一个账号一段时间内的作品时，调用 `list_account_video_metrics`。默认近 30 天、50 条；日期范围最长 90 天，显式上限 100 条。
3. 只有用户明确选择具体发布记录并要求读取评论时，才调用 `get_published_video_comments`，同时设置 `userConfirmed=true`。默认 20 条，最多 50 条。
4. 批量指标查询绝不自动读取评论。

所有分析工具的 `platform` 必须是单个字符串 `kuaishou`。用户同时要求多个平台时，用 `ask` action 要求先选快手或另一个平台；本 Skill 只继续快手。不能把平台传成数组，也不能循环调用多个平台。

## 账号与作品澄清

- 账号上下文不唯一时，先用 `get_account_status` 获取当前用户账号，再用 `ask` action 让用户选择一个快手账号。
- 历史发布记录返回多个作品候选时，把候选标题和时间做成 `ask` action，不猜测作品 ID。用户选择后，把候选 `accountId` 或 `platformWorkId` 作为单作品工具的可选确认参数再次调用。
- 工具返回 `needsClarification=true` 时必须停止当前查询，等待用户选择。
- 账号下非 Vidferry 发布的作品可参与批量排行，但必须标为“未关联本地原视频”，不要做内容总结归因。

## 输出分析

单作品展示播放、点赞、评论、分享以及工具返回的其他指标，并说明数据源、采集时间和相对上一快照的变化。字段为 `null` 就说明平台未提供，不补数。

批量分析至少说明样本量、日期范围和是否截断，并结合已关联视频的内容摘要、发布标题和标签解释高低表现。把相关性表述为观察结果，不声称因果。指标口径需要解释时，按需读取 `references/metrics.md`。

评论结果只分析正文、点赞数和时间。不要索取、推断或输出评论者昵称、头像和身份。

## 安全停止

工具返回登录失效、验证码、安全验证、限流、风控或页面结构变化时，立即停止，不自动重试，不切换账号，不建议验证码绕过、代理轮换、指纹伪装或未公开接口。说明需要用户在可见浏览器或账号管理中处理后再主动重试。

服务端可以在工具内部使用当前用户账号登录态，但凭据不得进入工具参数、工具结果、Agent 历史、回答或日志。
