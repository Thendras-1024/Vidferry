# 2026 年网络安全标准化研究课题申报准备清单

## 1. 结论

建议以 **“面向人工智能的网络安全技术与产品标准化研究”** 申报定向课题。现有“2030 项目”中与大模型内生安全相关的研究，可聚焦算法风险、训练与推理数据安全、模型篡改与对抗攻击、运行态安全、身份与权限管控，并将已有原型、评测结果和应用场景转化为标准化需求、指标和验证证据。

备选方向为 **“智能体插件与工具组件安全标准化研究”**。只有在项目已有 Agent 插件、工具调用、MCP/工具组件、权限边界或供应链治理等实质研究基础时，才建议选择该方向。每家单位只能牵头申报一项，应先在内部确定唯一方向。

## 3. 建议的申报定位

### 推荐课题名称

`面向大模型内生安全的网络安全技术与产品标准化研究`

名称需在最终申报时与定向课题主题“面向人工智能的网络安全技术与产品标准化研究”保持一致，不应将自定义题目包装成独立的第七项定向课题。

### 研究边界

围绕大模型从开发到运行的内生安全能力，形成可验证、可部署、可标准化的安全技术与产品要求：

- 训练与微调数据安全：来源可信、质量控制、投毒识别、敏感信息处理、数据全流程留痕。
- 模型与供应链安全：模型版本、权重与依赖完整性，模型篡改检测，可信发布和更新。
- 对抗与行为安全：提示注入、越权诱导、对抗样本、模型滥用、危险输出等风险的防护和评测。
- 运行态安全：输入输出安全、身份认证、权限控制、审计追溯、异常监测、应急处置。
- 测试评估：安全功能指标、检测能力、性能要求、测试方法与典型场景。

不建议承诺覆盖未掌握的通用内容安全、所有生成式 AI 风险或完整国家标准制定工作。申报内容须以“2030 项目”已经具备的技术、数据、系统和案例为证据基础。

### 拟形成成果

1. 《面向大模型内生安全的网络安全技术与产品标准化研究报告》。
2. 大模型内生安全能力框架、指标体系和测试评估方法。
3. 2 至 3 个可公开、脱敏的典型验证场景与结果。
4. 后续标准化建议：可形成的标准/实践指南方向、条款框架、适用对象和牵头工作组建议。

## 5. 研究报告建议目录

1. 研究背景、政策与产业需求。
2. 大模型内生安全概念、对象、适用范围与威胁模型。
3. 国内外标准与实践调研，以及与现有网络安全产品标准体系的差距。
4. 大模型内生安全能力框架。
5. 安全技术与产品功能要求：数据、模型、运行、身份权限、审计与应急。
6. 安全测试评估指标、测试方法与性能要求。
7. 典型场景验证：说明系统、数据脱敏方式、攻击/防护流程、量化结果和局限。
8. 标准化需求、拟制修订方向、条款框架与推进路线。
9. 结论与后续工作。

## 8. 内部决策建议

在申报前召开一次 30 分钟材料决策会，只确认四件事：

1. 是否以“面向人工智能的网络安全技术与产品标准化研究”作为唯一牵头方向。
2. 课题负责人、牵头单位和联合单位是否满足通知资格要求。
3. 哪些 2030 项目成果可脱敏公开并用于证明研究基础。
4. 是否接受成果知识产权归网安标委秘书处所有，以及结题前投入研究和公开研讨的资源安排。

## 9. 风险提示

- 通知要求结果可公开且无知识产权纠纷。不得直接附上涉密数据、未授权模型权重、客户日志或受第三方限制的材料。
- “大模型内生安全”是你方研究定位；对外申报须严格落在通知已列明的定向课题范围内。
- 通知只承诺对优秀成果给予“一定的课题研究补助经费”，未明确金额或发放条件，不应据此安排预算。
- 研究成果知识产权归属已在通知中明确，立项前需要法务或科研管理部门完成确认。
