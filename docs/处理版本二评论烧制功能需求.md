# 处理版本二评论烧制功能说明

## 功能目标

在处理版本二中可选烧制 YouTube 高质量评论，作为原作者信息、封面和高光片头结束后的正文内容补充。用户关闭开关时，不抓取评论、不调用评论筛选 LLM，也不影响现有成片。启用自定义字幕命令时不支持评论烧制。

## 触发与数据来源

评论不会在视频线索检索或链接导入时获取。仅在用户启用“评论烧制”并提交处理任务后，后台异步执行以下流程：

```text
yt-dlp 获取热门顶层评论（最多 100 条）
  -> 本地基础过滤与去重
  -> LLM 价值筛选与中文翻译
  -> 最多保留 20 条
  -> 按视频时长排期并写入 ASS
```

yt-dlp 以 `getcomments` 和 YouTube `comment_sort=top` 获取评论。项目使用并保留以下字段：

| 字段 | 用途 |
| --- | --- |
| `id` | 去重、筛选结果校验与缓存关联。 |
| `author` | 展示评论人名称。 |
| `text` | 展示原评论正文。 |
| `like_count` | 展示点赞数。 |
| `_time_text` | 可用时展示相对发布时间。 |
| `author_thumbnail` | 可下载时烧制圆形头像。 |
| `author_is_verified` / `author_is_uploader` / `is_favorited` | 保留为筛选和后续样式扩展信息。 |

YouTube 评论数据不提供中国大陆常见的 IP 属地字段，因此本功能不展示 IP。评论可用性受视频公开设置、地区限制和 yt-dlp 当前解析能力影响。

## 筛选与翻译规则

本地先剔除空内容、仅链接、重复文本、超长文本和明显脏话。随后由文本 LLM 从候选中选出最多 20 条：

- 保留与视频主题相关、有信息量、观点清晰或具互动价值的评论。
- 排除脏话、攻击、人身羞辱、广告引流、无意义字符、重复刷屏和价值观不符内容。
- 原文以简体或繁体中文为主、且不含日文假名时，仅展示原文；含少量汉字的外语混合评论仍翻译。
- 其他语言由 LLM 生成中文翻译，成片同时展示原文与中文翻译。

LLM 返回的评论 ID 必须来自当前候选集，且翻译不能为空、长度受限并再次经过脏话检查。

## 展示与排期规则

处理版本二的封面片头固定 2 秒；高光片头最多 3 段，每段 6 至 12 秒。评论层以正片时间轴为准：

- 第一条在正文开始后的第 60 秒显示。
- 单条从入场到退场共显示 8 秒；完全消失后留白 8 秒，再显示下一条。
- 入场使用轻微上浮与回弹，中段低幅度呼吸，退场淡出；所有动效计入 8 秒显示期。
- 超出视频总时长的评论不烧制，不阻塞任务。

单条样式位于视频左上区域，包含圆形头像（可用时）、评论人名称、相对发布时间（可用时）、原文、点赞数；非中文评论在原文下方显示中文翻译。文本按画面尺寸自适应，正文与翻译最多两行，过长部分以省略号截断。

## 失败降级与缓存

评论抓取、头像下载、LLM 筛选或翻译失败时，主字幕、封面和高光处理继续执行，任务状态会记录未烧制原因。常见原因包括视频未开放评论、无可用候选、LLM 未选出合格评论、模型请求超时和视频时长不足。

已筛选的评论快照会按视频与提示词版本缓存。相同处理设置再次执行时可复用缓存；视频、评论逻辑或提示词版本变化时会重新筛选。

## 验收标准

1. 关闭评论开关时，不发起评论网络请求或评论 LLM 调用。
2. 开启时最多请求 100 条热门顶层评论，最多选出 20 条。
3. 第一条从正文 60 秒处开始；单条完整显示 8 秒，消失后间隔 8 秒。
4. 中文或繁体中文评论只显示原文；其他语言显示原文与中文翻译。
5. 评论失败、无合格评论或视频过短时，主成片仍成功，且任务消息说明原因。
