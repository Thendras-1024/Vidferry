# 原视频字幕自动决策

## 目标

下载完成后，自动模式使用多模态 LLM 识别原视频对白字幕类别，再由后端决定是否烧制新字幕和是否启用固定底部遮罩。该判断不识别证据帧、字幕框或动态遮罩区域。

## 模式

| 模式 | LLM 判断 | 最终行为 |
| --- | --- | --- |
| `auto` | 是 | 按字幕类别派生处理动作 |
| `force_burn` | 否 | 始终烧制；遮罩由人工开关决定 |
| `original` | 否 | 保留原字幕，不烧制、不遮罩 |
| `legacy` | 否 | 保持历史任务已有的执行字段 |

自动模式的模型契约只有以下字段：

```json
{
  "classification": "non_zh",
  "reason": "检测到韩语对白字幕"
}
```

自动模式由后端按分类派生动作：`non_zh` 为“遮挡后烧制”，`none` 为“烧制”，`zh` 为“原字幕”。模型调用失败、返回非法结果或无法抽帧时，任务降级为“烧制，不遮罩”，不会中断处理。

## 任务快照

`source_subtitle_analysis` 继续使用既有 JSON 列，不新增迁移。v3 结果包含 `analysisVersion`、`classification`、`burnSubtitles`、`subtitleMaskEnabled` 和 `reason`，并保存派生后的最终动作供任务详情显示。

旧自动分析结果若缺少完整 v2 决策，会在下一次执行该任务时重新判断；已完成的历史任务不会主动重跑。

## 遮罩与渲染

遮罩使用固定底部区域：先对该区域做模糊和细颗粒马赛克，再叠加 ASS 字幕。正文和高光采用相同的固定几何；不做字幕框检测、横纵坐标适配或逐帧跟踪。

任务详情和素材详情只显示“原字幕”“烧制”或“遮挡后烧制”，以及判断原因。
