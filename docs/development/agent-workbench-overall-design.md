# Vidferry Agent 工作台总体设计方案

## 1. 目标

将原本位于右侧抽屉中的 Vidferry Agent 改为登录后的首页工作台，并用统一壳层承载视频采集、账号连接、素材管理、发布和自动化任务页面。

- 登录后默认进入 `/`，右侧显示 Agent 对话。
- 左侧只有一列，垂直划分为 Part1、Part2、Part3。
- Part1 和 Part3 固定，Part2 独立滚动。
- Part4 是统一主工作区，可显示 Agent 对话或现有业务页面。
- 保留现有 Agent SSE、历史消息、确认动作、视频上下文和飞书只读会话能力。
- 不展示尚未实现的分享、语音、附件上传、模型切换和工作区选择。

## 2. 总体布局

```text
┌──────────────────────┬──────────────────────────────────────┐
│ Part1 固定业务导航    │ 顶部栏：折叠按钮 / 当前页面标题 / 页面操作 │
│                      ├──────────────────────────────────────┤
│ 新建对话             │                                      │
│ 视频采集与处理        │                                      │
│ 账号连接             │                                      │
│ 视频素材             │          Part4 主工作区                 │
│ 发布中心             │      Agent 对话或业务页面内容            │
│ 自动化任务           │                                      │
├──────────────────────┤                                      │
│ Part2 会话列表        │                                      │
│                      │                                      │
│ 置顶会话             │                                      │
│ 最近会话             │                                      │
│ 历史会话             │                                      │
│ 该区域独立滚动        │                                      │
├──────────────────────┤                                      │
│ Part3 用户区域        │                                      │
│ 头像 / 用户名 / 状态  │                                      │
└──────────────────────┴──────────────────────────────────────┘
```

桌面端左栏展开宽度为 `292px`，折叠宽度为 `72px`。窄屏下折叠栏保留在左侧，展开时覆盖主工作区，避免持续压缩对话输入区域。

## 3. 视觉规范

主题是“本地视频生产流水线 + 可审计 Agent”，整体保持安静、清晰、适合高频操作。

| Token | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F5F7F8` | 工作区背景 |
| 主文字 | `#17212B` | 标题和主要信息 |
| 主操作 | `#0F766E` | 新建对话、发送和 Agent 状态 |
| 流水线标记 | `#D97745` | 当前业务导航的左侧轨道 |
| 警告 | `#C58A27` | 配置待检查和异常状态 |
| 分隔线 | `#DDE5E8` | 区域边界 |

中文使用 `Noto Sans SC`、`Microsoft YaHei` 和系统无衬线字体回退；时间、状态和英文标签使用 `Inter` 或系统无衬线字体。界面不使用装饰性渐变、光晕和营销式大卡片。

## 4. Part1：固定业务导航

菜单顺序固定为：

1. 新建对话
2. 视频采集与处理
3. 账号连接
4. 视频素材
5. 发布中心
6. 自动化任务

命名规则：

- “账号管理”对用户显示为“账号连接”，只展示账号标识、登录状态和 Cookie 有效性，不展示 Cookie 原文。
- “视频素材管理”缩短为“视频素材”。
- “定时发布任务列表”改为“自动化任务”，首期仍显示现有定时发布数据。
- 处理统计、用户与安全、字幕审计和运行诊断归入管理员入口。
- 关于、版本和帮助归入 Part3。

当前菜单使用细珊瑚色左轨道表示所在业务阶段，其他菜单不使用额外装饰。

## 5. Part2：会话列表

会话列表始终保留，业务页面切换不卸载会话导航。

- 显示会话名称、来源或更新时间。
- 当前会话高亮。
- 悬停或键盘聚焦时显示 `...` 操作。
- 支持置顶、取消置顶、重命名和删除。
- 搜索、来源筛选和刷新收纳到紧凑工具区。
- 点击会话后 Part4 切换到 Agent 首页并恢复该会话。

排序规则：

1. 置顶会话优先。
2. 置顶会话按 `pinnedAt` 降序排列，后置顶的排在前面。
3. 未置顶会话按 `updatedAt` 降序排列。

首期将 `title`、`isPinned` 和 `pinnedAt` 保存在浏览器本地，避免在总体壳层阶段修改数据库。后续 Part2 专项实施时，再补充服务端字段和重命名、置顶接口，实现跨设备同步。

## 6. Part3：用户与运行状态

左下角固定显示头像、用户名、角色、任务中心、未读消息和飞书机器人状态。

头像菜单包含：

- 修改密码
- 帮助与版本
- 退出登录

管理员额外显示：

- 用户与安全
- 处理统计
- 字幕审计与诊断

顶部栏不再重复显示用户头像、消息和飞书状态，只保留侧栏折叠、当前页面标题和页面级操作。

## 7. 设置归属

现有设置内容属于视频工作流默认配置，不属于个人账户设置，也不应藏在全局头像菜单中。

```text
Part1
└── 视频采集与处理
    └── 处理配置

Part3
└── 头像菜单
    ├── 修改密码
    ├── 帮助与版本
    ├── 管理员入口
    └── 退出登录
```

“视频采集与处理”页面顶部提供“处理配置”按钮，打开 `/workflow-settings` 独立页面。该页面保留五个设置分组：

- 处理方案
- 字幕与输出
- 翻译与拼接
- 封面片头
- 水印标识

配置仍通过 `/youtube/workflow/settings` 读取和保存。旧设置弹窗暂时保留供现有视频处理页面内部兼容，不再作为全局入口。

## 8. Part4：主工作区

Part4 根据当前路由显示内容：

| 路由 | 内容 |
| --- | --- |
| `/` | Agent 对话 |
| `/youtube-research` | 视频采集与处理 |
| `/workflow-settings` | 工作流默认处理配置 |
| `/account-management` | 账号连接与 Cookie 状态 |
| `/material-management` | 视频素材 |
| `/publish-center` | 发布中心 |
| `/scheduled-publish-tasks` | 自动化任务 |

Agent 对话保留会话标题、来源状态、流式消息、结果卡片、动作确认、复制、重试、视频上下文和飞书只读提示。输入框固定在底部，消息区域独立滚动。

## 9. 实施边界

本次总体壳层阶段已完成：

- Agent 作为登录后首页。
- 左侧单列 Part1、Part2、Part3。
- 右侧 Part4 路由工作区。
- 会话本地置顶和重命名。
- 消息、任务中心、飞书状态和用户菜单迁移到 Part3。
- 独立处理配置页面。

后续 Part1 至 Part4 专项文档分别定义页面内部信息密度、服务端会话元数据、角色权限和 Agent 消息细节。总体方案不预先增加自动化任务执行器、Agent 偏好配置或新数据库 schema。

## 10. 验收标准

- 登录后 `/` 显示 Agent 工作台。
- 左侧只有一列，Part1 和 Part3 固定，Part2 独立滚动。
- 点击业务菜单只替换 Part4，点击会话返回对应 Agent 对话。
- 多个置顶会话按最新置顶时间排序。
- 普通用户不显示管理员菜单。
- 处理配置可以独立读取、修改和保存现有字段。
- Agent 流式响应、错误、重试、动作确认、视频上下文和飞书只读状态保持可用。
- 桌面、窄屏和移动端无重叠，图标按钮具备可访问名称。
- 前端通过 `npm run build` 和 `git diff --check`。
