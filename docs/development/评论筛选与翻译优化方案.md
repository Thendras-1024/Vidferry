# 评论筛选与翻译优化方案

## 流程

1. 从 YouTube 抓取最多 100 条热门评论，使用严格正则过滤明确脏话、纯链接和重复内容。英文只按完整单词匹配，中文只匹配明确多字词组，不因单个汉字过滤。
2. 过滤后的评论每 20 条为一批进行 LLM 初筛；每批最多保留 5 条，初筛只返回评论 ID 与评分。初筛最多并发 2 批，每批超时为 `min(LLM_TIMEOUT, 60)` 秒；各批独立失败，不取消其他批次。
3. 汇总成功批次后进行一次全局选择，最多保留 20 条。全局选择失败时，按初筛评分回退。单个初筛批次失败不会影响其余批次。
4. 中文占主要文字内容的评论直接保留；含少量汉字的外语混合评论仍视为非中文。非中文评论先走现有 Google 初译链路。模式为 `google_llm` 时，再按现有字幕 LLM 修订链路处理。LLM 修订失败时保留 Google 初译；Google 初译失败的非中文评论不烧制。

## 用户选择与结果

处理设置在“烧制评论”开启后提供两种模式：

- `Google 初译 + LLM 修订`：默认，优先译文质量。
- `Google 初译`：优先速度。

模式作为 `commentTranslationMode` 保存到任务。评论少于 20 条时仍正常烧制，并在结果中显示实际烧制数量；任务快照记录抓取数、严格正则过滤、初筛批次、最终选择、实际译出数量和翻译回退统计。若已选评论全部初译失败，任务须明确显示翻译失败，而不是误报为未选出合格评论。

## 验收标准

- 100 条评论会拆分为 5 个、每个最多 20 条的初筛请求。
- 初筛批次最多并发 2 个，单批失败不阻塞其他批次，且批次结果仍按原始顺序汇总。
- 任何单个初筛或 LLM 修订批次失败，已有有效结果仍可继续烧制。
- 翻译模式在创建任务、重新处理和任务查询中保持一致。
